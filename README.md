# Analisis_sentimen_menggunakan_SVM_-_Naive_Bayes
Skripsi : ANALISIS SENTIMEN OPINI PUBLIK TERHADAP  KECURANGAN PEMILU PRESIDEN 2024 MENGGUNAKAN  ALGORITMA SUPPORT VECTOR MACHINE DAN NAÏVE  BAYES 

Repository ini berisi source code skripsi dengan topik analisis sentimen data Twitter
menggunakan algoritma Support Vector Machine (SVM) dan Naive Bayes.

## Dataset
Data dikumpulkan melalui proses crawling Twitter menggunakan Twitter API.

## Metodologi
- Preprocessing teks
- Ekstraksi fitur (TF-IDF)
- Klasifikasi menggunakan:
  - Support Vector Machine (SVM)
  - Naive Bayes

## Tools
- Python
- Google Colab
- Scikit-learn
